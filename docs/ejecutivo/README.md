# PharmaPOS — Guías para la farmacia

Documentos para el dueño, la familia y el personal. Explican qué hace cada parte del sistema, cómo
se usa, qué protege y qué no hace todavía. No requieren conocimientos técnicos.

## Para empezar

- **[Guía rápida del cajero](GUIA_CAJERO.md)** — escáner, teclas rápidas, cobro, ticket o nota de
  remisión, y qué hacer con los avisos de "sin conexión" y "versión nueva". Imprímela y déjala en
  la caja.

## Ideas clave

- **El servidor es la memoria del negocio.** Cada venta, pago y movimiento se guarda al momento.
  Si se cierra la página, nada se pierde; si el servidor no responde, no se puede cobrar.
- **Cada persona, su usuario.** Así cada acción tiene responsable.
- **Lo delicado deja rastro**: descuentos autorizados, aperturas de cajón, anulaciones, ajustes de
  inventario, impresiones y cambios de configuración.
- **La nota de remisión no es factura.**
