# Dashboard (panel financiero)

## Qué hace

Es la pantalla de inicio. Para quien tiene permiso de reportes muestra, para el periodo elegido:

- **Ventas totales, costo, utilidad bruta, margen, ticket promedio y número de ventas.**
- **Liquidez actual**: lo que te deben los clientes, lo que debes a proveedores y el valor del
  inventario.
- **Ventas por forma de pago** (gráfica de dona).
- **Top 5 productos** por ingreso.

## Cómo se usa

1. Al entrar se muestra el **mes en curso**.
2. Botones **Este mes** y **Mes pasado**, o elige fechas y busca.

## Qué protege

- Sólo lo ve quien tiene el permiso de reportes; los demás ven "Acceso Restringido".

## Limitaciones

- Si el servidor no responde, la pantalla queda sin datos (no muestra un mensaje propio).
- Es un resumen: el detalle de cada venta está en **Ventas**.

## Consejos de operación

- Compara el margen de este mes con el anterior cada semana.
- Si las cuentas por cobrar crecen, revisa **Clientes › Deudores**.
