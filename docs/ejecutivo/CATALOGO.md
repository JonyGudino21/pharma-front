# Catálogo: productos y categorías

## Qué hace

Registra los productos que vende la farmacia (nombre, presentación, código de barras, precio,
costo, IVA, si es controlado, existencia mínima) y los agrupa en categorías.

## Cómo se usa

**Dar de alta un producto**
1. Catálogo → Productos → **Nuevo producto**.
2. Captura nombre, concentración, forma y presentación (el sistema genera el código interno SKU),
   código de barras, categorías, precio y costo.
3. Indica si es **controlado** y su **tratamiento de IVA** (el sistema propone el configurado).
4. Si ya tienes piezas, escribe la existencia inicial con su **lote y caducidad**.
5. Guarda.

**Editar o dar de baja**: botones en cada fila. La baja no borra el producto; deja de venderse.

**Categorías**: Catálogo → Categorías → crear, editar o desactivar.

## Qué protege

- Precio y costo deben ser mayores a cero: no se venden productos "gratis" por error.
- El IVA de un producto existente sólo lo cambia gerencia.
- Las existencias no se modifican al editar el producto: sólo con compras, ajustes o ventas.
- No se puede dar de alta inventario ya caducado.
- El costo sólo lo ve quien administra productos.

## Limitaciones

- Cualquier usuario puede consultar el catálogo; sólo quien tiene permiso lo modifica.
- Para cambiar el IVA de muchos productos a la vez, usa **Configuración › Impuestos** (por
  categoría).

## Consejos de operación

- Captura siempre el código de barras: agiliza el cobro.
- Usa categorías claras (p. ej. "Antibióticos", "Higiene"): sirven para asignar IVA en bloque.
- Define una existencia mínima realista para recibir alertas de stock bajo.
